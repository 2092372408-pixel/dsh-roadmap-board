# roadmap.json 结构（v0.1 schema）

每个项目一份，位于 `<项目根>/.progress/roadmap.json`。UTF-8 JSON，字段宽松（缺失自动回退），但推荐完整填写。

## 顶层

| 字段 | 类型 | 说明 |
|---|---|---|
| `title` | string | 看板大标题（页面顶栏展示），如“教育智能体 · 执行路线” |
| `note` | string | 一行状态：当前在做什么 / 下一步（状态条空闲时显示） |
| `panel` | object | 面板记忆：`x,y,open,w,h`（用户拖动/缩放自动写回，可不手工维护） |
| `globals` | string[] | 全局技能名：**每执行一步前都要先加载** |
| `lanes` | Lane[] | 横向执行的阶段顺序（阶段0 → 阶段1 → …） |

## Lane（阶段 = 模块）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 id（可选；缺省自动生成） |
| `title` | string | 阶段名 |
| `steps` | Step[] | 该阶段内的步骤，**数组顺序 = 执行顺序** |

## Step（步骤）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 id（可选） |
| `text` | string | 步骤内容（≤300） |
| `state` | enum | `todo / doing / done / fix / blocked`；**全程至多一条 doing** |
| `skill` | string | 执行本步前需加载的技能名（须存在于该项目的技能库）；空串 = 不绑定 |
| `branches` | Branch[] | 返工/完善分支，挂在所属步骤下，**绝不打断主线**（右侧栏展示） |

## Branch

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | 唯一 id（可选） |
| `text` | string | 分支内容（≤200） |
| `state` | enum | 同上 |

## 语义约定（LangGraph 式的“图”而非线性“链”）

- 阶段 = 并行/顺序的可编排单元；阶段间用箭头表示主线顺序；
- 同一阶段内步骤默认顺序执行（卡间 ↓ 箭头）；
- 返工/完善 = Step.branches，右侧「修复/完善」栏展示，不影响主线；
- 技能绑定 = Step.skill / 顶层 globals，让“执行该步前加载正确能力”成为结构的一部分。

## 数据边界

- 面板编辑（增删改待办/排序/绑技能）与智能体写回（状态推进）都以本文件为准；
- 不保存派生状态；`startTs/doneTs` 计时字段已移除（v51 起不维护）。

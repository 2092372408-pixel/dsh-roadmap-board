# 智能体工作协议（Agent Protocol v1）

> 适用对象：使用本看板的任何 agent preset。目标：**不跑偏、按路线执行、岔路开分支、完成即写回**。

## 唯一事实源

当前项目路线 = `<项目根>/.progress/roadmap.json`。面板与 AI 通过**同一份文件**双向同步：
- 人在面板编辑（结构/技能/顺序）→ 写回该文件；
- AI 用文件工具读写该文件 → 面板 1.5s 内采纳并高亮（write/edit 均触发镜像）。

## AI 每轮操作规则

1. **先读地图**：回合开始先读 roadmap.json（含 `title/note/globals/lanes`）与项目 PLAN，定位唯一 `doing`；**用户手动增删改过的待办项必须保留**，以其当前文件为准合并。
2. **只做 doing**：路线之外的改动不启动；新需求先落成 `todo` 步骤再执行（追加到合适阶段，或用面板编辑）。
3. **技能先加载**：执行某步前，先加载该步 `skill` 与顶层 `globals` 中列出的技能（须存在于 `<项目根>/.agents/skills` 或平台技能库，不存在则如实说明）。
4. **岔路开分支**：发现问题/返工/完善 → 在该步骤下新增 `branches` 项（写清原因），处理后标 `done` 回到主线；分支永远挂在所属步骤，不产生新主线。
5. **每动作写回**：任何状态变化（todo→doing→done/fix/blocked）与 note（当前/下一步）立即整文件写回；至多一条 doing。
6. **回合自检**：无悬空 doing；不覆盖用户手动改动；与项目 CHANGELOG 不矛盾；阶段收尾更新 CHANGELOG。

## 状态机

`todo → doing → done`；出错/返工：`doing/fix`；长期受阻：`blocked`（必须写明原因到分支）。
